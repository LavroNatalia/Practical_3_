# Practical Work 3 — FastAPI

## Опис проєкту
Навчальний Python-проєкт, створений за допомогою менеджера пакетів uv та вебфреймворку FastAPI.

## Використані технології
- Python
- uv
- FastAPI
- Ruff
- pre-commit
- Git

## Інструкція із запуску

1. Встановити Python та uv.
2. Відкрити папку проєкту в терміналі.
3. Встановити залежності:

```bash
uv sync
```

4. Запустити сервер:

```bash
uv run fastapi dev main.py
```

5. Відкрити у браузері:

http://127.0.0.1:8000

## Очікуваний результат

Після запуску сервер повертає:

```json
{"message": "Hello World!"}
```
